# Projeto 03: Magic 8 Ball (Bola Mágica de Respostas)

Este projeto foi desenvolvido no âmbito do projeto de extensão **Elas Programando**. O aplicativo simula a famosa brincadeira da "Bola 8 Mágica", onde o utilizador faz uma pergunta mentalmente ou em voz alta e interage com o telemóvel para receber uma resposta mística gerada aleatoriamente pelo sistema.

## Funcionalidades
* **Gerador de Respostas Aleatórias:** Sorteio dinâmico de frases de resposta (positivas, negativas ou evasivas) a partir de uma lista pré-configurada.
* **Feedback Sonoro:** Reprodução de um efeito de som misterioso a cada nova previsão revelada na tela.

---

## Conceitos de Programação Aprendidos
* **Estrutura de Dados (Listas):** Criação e manipulação de listas de blocos de texto no MIT App Inventor para armazenar todas as respostas possíveis da bola mágica.
* **Lógica de Randomização (`pick a random item`):** Uso de funções matemáticas e de listas para sortear de forma puramente aleatória um dos itens guardados na memória do app.
* **Componentes de Áudio (`Sound`):** Controle de reprodução de arquivos de som de curta duração acionados por eventos de clique ou interações de botões.
